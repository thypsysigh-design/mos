# 몬스터 엑셀 관리

원본 파일은 [monsters.xlsx](monsters.xlsx)입니다. 수정한 파일을 대화에 첨부하거나 저장소의 파일을 교체하면 됩니다. 게임을 다시 실행하거나 빌드할 때 반영하며, 기존 다운로드 HTML은 자동 변경되지 않습니다.

## Monsters 시트

몬스터 한 마리당 한 행입니다. 행을 추가하면 새 몬스터도 추가됩니다.

| 열 | 설정 내용 |
| --- | --- |
| ID | 중복되지 않는 영문 식별자. 예: forest_ghost. 저장된 전투에 영향을 줄 수 있으므로 기존 ID 유지 권장 |
| ko_name / en_name / ja_name | 이름과 번역. 번역이 없으면 한국어 사용 |
| 종류 | normal: 일반 전투 / boss: 보스 전투 |
| 전투력 | 기본 공격력. 방어력과 스킬 등에 따라 실제 피해는 달라짐 |
| 체력 | 전투 시작 시 최대 체력 |
| 레벨 | 몬스터 표시 레벨(1~30). 별도 자동 능력치 배율은 없으며 전투력·체력으로 조정 |
| 등장_최소레벨 / 등장_최대레벨 | 등장 가능한 플레이어 레벨 범위(1~30, 양끝 포함) |
| 공격유형 | physical: 물리 / magic: 주술 |
| 물리방어 / 주술방어 | 각 공격 유형의 피해 감소량 |

해당 전투 종류와 플레이어 레벨 조건을 만족하는 몬스터 중 균등 추첨합니다. 일반 전투와 보스 전투 각각 플레이어 레벨 1~30 전체를 최소 한 마리로 채워야 합니다. 누락 구간이 있으면 데이터 반영을 중단하고 오류를 알립니다. 기존 모험의 보스 등장 날짜와 경험치·냥 보상은 유지됩니다.

## Drops 시트

몬스터ID와 아이템ID 조합당 한 행을 입력합니다. 아이템ID는 [items.xlsx](items.xlsx)의 ID를 사용합니다. 같은 몬스터에 여러 행을 추가할 수 있습니다.

`드랍확률(%)`는 0~100 숫자로 입력하세요. **25를 입력하면 25%**입니다(엑셀 백분율 서식 사용 금지).
몬스터당 확률 합계는 100 이하이며 한 전투에서 최대 한 아이템을 지급합니다. 합계 40이면 무드랍 확률은 60%입니다. 드랍 행이 없으면 아이템을 주지 않습니다. 이미 보유한 장비에 당첨되면 중복 지급하거나 다시 추첨하지 않습니다.

예: mist / potion / 30, mist / spirit_potion / 10 → 산삼 탕약 30%, 영지 환약 10%, 무드랍 60%.

진행 중인 전투는 시작 시점의 몬스터 능력치와 드랍 설정을 저장하므로 엑셀 수정 후에도 결과가 바뀌지 않습니다. 다음 전투부터 새 설정을 사용합니다. 기존 저장의 예전 전투는 이전 드랍 규칙으로 마무리합니다.

## 개발자 명령

- `npm run monsters:import`: 엑셀을 src/data/monsters.json에 반영
- `npm run monsters:check`: 원본과 생성 파일 일치 확인
- 게임 실행·빌드 전 자동 반영, 테스트 전 일치 검증

생성 JSON은 직접 수정하지 마세요. 수식·중복 ID·잘못된 아이템·범위를 벗어난 값은 반영 단계에서 거부합니다.
