# 아이템 엑셀 관리

아이템의 원본은 **items.xlsx**, 일반 화면 문구와 번역의 원본은 **game-texts.xlsx**입니다.
아이템 이름을 두 파일에서 중복 관리하지 않도록 기존 아이템 이름·효과 설명 행은 items.xlsx로 옮겼습니다.

`Items` 시트에서 아래 열을 수정할 수 있습니다.

| 열 | 용도 |
| --- | --- |
| ko_name | 한국어 아이템 이름 |
| en_name / ja_name | 영어·일본어 아이템 이름. 비어 있으면 한국어 사용 |
| 수치 | 공격력·방어력 증가량 또는 체력·정신력 회복량 |
| 구매가 / 판매가 | 상점 가격. 판매가는 구매가보다 클 수 없음 |
| ko_flavor / en_flavor / ja_flavor | 선택적인 추가 설명 |

효과는 `physical_attack`(물리 공격력), `defense`(물리·주술 방어력), `heal_hp`(체력 회복),
`heal_mp`(정신력 회복) 중 하나입니다. 게임의 효과 설명은 **효과와 수치에서 자동 생성**합니다.
예를 들어 탕약 수치를 12에서 20으로 바꾸면 실제 회복량과 화면의 `체력 20 회복`이 함께 바뀝니다.

기존 5개 ID는 저장·이야기와 연결되어 있으므로 변경하거나 삭제하지 마세요. 신규 아이템이나
복합 효과를 추가하려면 개발 작업이 필요합니다. 장비의 슬롯과 효과는 대응해야 합니다.
weapon은 physical_attack, armor는 defense입니다. 두 소비품의 효과 종류는 유지하세요.

수정 후 저장한 파일을 이 대화에 첨부하거나 GitHub의 `content/items.xlsx`를 교체하세요.
이미 배포한 HTML은 자동으로 바뀌지 않으며 요청하실 때 다시 만듭니다.

개발자 명령:

```sh
npm run items:import
npm run items:check
```

게임 실행·빌드 전에는 아이템과 문구 엑셀을 함께 반영합니다. 생성된 `src/data/items.json`을
직접 수정하지 마세요. 아이템 효과 설명의 번역 형식은 game-texts.xlsx의 `items.effect.*`에서 관리합니다.
