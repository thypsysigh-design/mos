# 게임 문구 엑셀 관리

원본은 **game-texts.xlsx**입니다. 게임 코드를 열지 않고 문구와 번역을 수정할 수 있습니다.

1. 엑셀 파일을 내려받아 열고 **Texts** 시트를 선택합니다.
2. **ko** 열에서 한국어를 수정합니다. **en**은 영어, **ja**는 일본어 번역입니다.
3. `.xlsx` 형식으로 저장한 뒤 GitHub의 같은 파일을 교체하거나, 이 대화에 파일을 첨부합니다.
4. 게임을 다시 실행하거나 빌드하면 반영됩니다. 이미 만들어진 HTML은 자동으로 바뀌지 않습니다.

처음에는 다음 ID를 검색하면 됩니다.

| ID | 내용 |
| --- | --- |
| common.title | 게임 제목 |
| common.subtitle | 부제 |
| title.intro | 첫 화면 소개 문구 |
| button.enter | 첫 화면 시작 버튼 |
| prologue.title | 프롤로그 제목 |
| prologue.body | 프롤로그 본문 |
| button.next_stats | 직업 선택에서 스탯 분배로 이동 |
| button.back_to_class | 스탯 분배에서 직업 선택으로 돌아가기 |
| creation.allocation_step | 스탯 분배 화면 안내 |
| button.start_game | 게임 시작 버튼 |

**ID를 변경하거나 기존 행을 삭제하지 마세요.** 분류·위치·메모는 관리용 정보입니다.
문장 안의 `{day}`, `{name}` 같은 표시는 게임이 숫자나 이름을 넣는 자리입니다.
표시 이름을 그대로 유지한 채 위치만 옮길 수 있습니다. 한국어와 번역에는 같은 표시가 있어야 합니다.
줄바꿈은 셀 안에서 **Alt+Enter**로 입력합니다. 수식은 사용하지 않습니다.

번역을 비워 두면 한국어를 표시합니다. 영어와 일본어 번역은 아직 작성하지 않았습니다.
추가 언어가 필요하면 `zh`, `fr`, `pt-BR`처럼 언어 코드 열을 추가할 수 있습니다.

개발자는 아래 명령으로 수정 내용을 반영·검증합니다.

```sh
npm run texts:import  # Excel → 게임용 JSON
npm run texts:check   # 엑셀과 생성 데이터의 일치 확인
npm test             # 게임 및 번역 데이터 검사
```

`npm start`, `npm run web`, Android/iOS 실행, export 및 playtest에는 자동 변환이 연결되어 있습니다.
실행 언어는 시작 전에 `EXPO_PUBLIC_GAME_LOCALE=en`처럼 지정합니다. 기본값은 `ko`입니다.
언어 선택 화면과 실행 중 언어 전환은 아직 제공하지 않습니다.

`src/localization/*.json`과 `catalogs.ts`는 생성 파일입니다. 직접 수정하면 다음 변환 때 덮어씁니다.
`text-manifest.json`은 코드가 요구하는 문구 ID와 변수 목록을 기록한 개발용 파일입니다.
문구를 새로 추가하거나 변수 구조를 바꿀 때는 개발자가 이 파일과 호출 코드를 함께 수정합니다.

기존 저장 파일의 결말 식별자는 번역과 분리하여 유지합니다. 이미 기록된 여정·전투 문장은
당시 언어의 문장 그대로 저장되어 있으며, 나중에 번역해도 과거 기록까지 바뀌지는 않습니다.
다운로드용 HTML은 사용자가 요청할 때만 다시 만듭니다.

아이템 이름·효과 수치·가격·아이템 번역은 별도의 [items.xlsx](items.xlsx)에서 관리합니다. [아이템 관리 안내](ITEMS.md)를 참고하세요.
