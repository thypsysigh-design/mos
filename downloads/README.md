# 이매망량의 주인
## 부제: 산군 / PC 테스트 v0.3

1. `mos-playtest-v3.zip`을 내려받습니다.
2. 압축을 풉니다.
3. `mos-playtest-v3.html`을 Chrome 또는 Edge로 엽니다.

계정 연결, 별도 설치, 서버 실행 없이 플레이하는 PC 테스트용 파일입니다.

전투는 시작 시 자동으로 승패까지 진행됩니다. 직업 기술·방어·탕약도 자동으로 사용합니다.
전투 결과에는 승패, 체력 변화, 냥·경험치·전리품과 전체 전투 기록을 표시합니다.
패배나 보스 승리로 모험이 끝나도 전투 결과를 확인할 수 있습니다.

바로 싸워 보려면: 검사 선택 → 숲으로 들어가기 → 성문 밖 도깨비와 맞선다.
저장은 같은 브라우저와 파일 경로의 로컬 저장소에 보관합니다.
이전 버전 ZIP은 보관되어 있으며 최신 버전은 v3입니다.
