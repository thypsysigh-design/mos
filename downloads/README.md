# 사령패 — 잔향의 숲 / PC 테스트 v0.2

1. `mos-playtest-v2.zip`을 내려받습니다.
2. 압축을 풉니다.
3. `mos-playtest-v2.html`을 Chrome 또는 Edge로 엽니다.

계정 연결, 별도 설치, 서버 실행 없이 플레이하는 PC 테스트용 파일입니다.

## 이번 버전

- 조선 요괴사냥 분위기와 먹빛·한지 화면
- 검사·무당·포수·승려의 네 가지 직업
- 공격·방어·직업 기술·탕약·도주를 선택하는 턴제 전투
- 적의 다음 행동 예고, 체력·기력·전투 로그
- 승리 보상, 경험치·레벨, 장비 획득과 착용, 마지막 대감신 전투
- 전투 중 자동 저장·복원, PC에서 모험 포기 확인

바로 싸워 보려면: 검사 선택 → 숲으로 들어가기 → 성문 밖 도깨비와 맞선다.
현재 진행과 모험집은 같은 브라우저의 로컬 저장소에 보관합니다.
파일 경로 변경이나 브라우저 데이터 삭제 시 기록이 달라지거나 삭제될 수 있습니다.
Android·iOS 설치 파일은 아닙니다.
