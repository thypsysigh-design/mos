# 이매망량의 주인 — 산군

## PC 테스트 v0.4

`mos-playtest-v4.zip`을 내려받아 압축을 풀고 `mos-playtest-v4.html`을 Chrome 또는 Edge로 엽니다.

화면 순서: 타이틀·접속 → 프롤로그·직업 선택 → 게임 시작.
저장된 게임은 접속 → 프롤로그 → 모험 이어하기로 열립니다.
게임 메뉴는 실제 게임 화면에서만 표시합니다.
전투는 자동으로 승패까지 진행되고 보상과 전체 전투 기록을 보여줍니다.
계정이나 서버, 별도 프로그램 설치는 필요하지 않습니다.
이전 버전 ZIP은 보관되어 있으며 최신 버전은 v4입니다.
